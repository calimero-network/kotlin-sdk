---
title: Quickstart
description: Add mero-kotlin, point a CalimeroClient at a Calimero 1.0 cluster (or merod local), sign in with a passkey and call an app.
---

mero-kotlin is the Android client for **Calimero 1.0**, the confidential cloud: apps run on
clusters of attested TDX nodes, and a client talks to them only after it has verified the node's
quote, over a sealed channel. It mirrors mero-js ≥ 27's `CalimeroClient` one to one.

## 1. Add the dependency

```kotlin
dependencies {
    implementation("com.calimero.mero:mero-core:<version>")     // CalimeroClient, attestation, sealed transport
    implementation("com.calimero.mero:mero-compose:<version>")  // MeroAppSession, PlatformPasskey, ConsentLauncher
    testImplementation("com.calimero.mero:mero-testkit:<version>") // InMemoryAppBackend
}
```

## 2. A local cluster

```bash
# in calimero-network/core
cargo run -p merod -- local    # three nodes on 127.0.0.1:2501-2503, --dev, mock attestation
```

From the Android emulator the host is `10.0.2.2`, so the node is `http://10.0.2.2:2501`.
`merod local` signs a **mock** quote: a client must opt in with `allowMock`, and only ever for a
node you run.

## 3. Sign in and call

```kotlin
val client = CalimeroClient(
    CalimeroClientOptions(
        baseUrl = "http://10.0.2.2:2501",
        policy = CloudPolicy.development,          // allowMock = true: merod local only
        onSession = sessionStore::save,            // keep the newest session (refresh tokens are single-use)
    ),
)

// A development cluster: a software passkey (keep it with export()/restore()).
val passkey = SoftPasskey(rpId = "localhost", origin = "http://localhost:3000")
client.signUp(passkey, "ada")

val appId = client.createApp("kv", AppSource.Package("com.calimero.kv-store"), initArgs = buildJsonObject {})
client.call(appId, "set", buildJsonObject { put("key", "a"); put("value", "1") })
val value = client.view(appId, "get", buildJsonObject { put("key", "a") }).result
client.events(appId).collect { println("${it.kind}: ${it.data}") }
```

Against a real cluster, trust real quotes only, and sign in with the device's passkey:

```kotlin
val client = CalimeroClient(CalimeroClientOptions(baseUrl = clusterUrl, policy = CloudPolicy.production))
client.signIn(PlatformPasskey(activity))   // Android Credential Manager
```

`CloudPolicy.production` is `CloudReleasePolicy(DEFAULT_MIN_RELEASE)`: the node must name a
mero-tee release at or above `2.3.109`, signed by the mero-tee release workflow, and its quote
must match that release's `locked-read-only` image, with Intel's collateral checked on the device.

## 4. A Compose app

Most apps should not hold a client at all: `MeroAppSession` keeps the session, and its
`MeroAppBackend` is what screens use. See [App session](/guides/app-session/).
