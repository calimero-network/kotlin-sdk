---
title: Apps
description: Create app instances from packages, call intents, read views, stream events, store blobs and publish presence.
---

## Create an instance

```kotlin
val appId = client.apps.create(
    name = "general",
    `package` = "com.calimero.chat",                       // installed from the registry if missing
    org = orgId,
    access = AppAccess.Team(teamId),                       // or Owner, Org, Public, Accounts(…)
    initArgs = buildJsonObject { put("name", "general") },
).appId
```

A raw bundle (`client.packages.bundlePut`, then `apps.create(bundle = hash)`) and `.mpk` uploads
(`client.packages.upload`) work only on a `--dev` cluster; production installs only from the registry
(`client.packages.install`).

## Calls and views

```kotlin
val call = client.apps.intents(app = appId, method = "send_message", args = args)   // index, result, events, receipt
val view = client.apps.views(app = appId, method = "get_messages", args = args)    // index, result; consistency = STALE reads any replica
```

`intents` mints an idempotency key (`node:c-…`) unless you give one, and retries a `503` or a dropped
connection with the **same key** (6 times, 200 ms doubling to 2 s). When it gives up it throws
`UnavailableError`, whose `committed` is `Committed.No` (the node said it did not run) or
`Committed.Unknown`. An app's own refusal is `AppError(appCode, fields)`.

## Events

```kotlin
client.events(appId, from = 0).collect { event -> /* event.kind, event.data */ }
```

A sealed server-sent event stream; cancel the collecting coroutine to close it.

## Blobs and presence

```kotlin
val blob = client.uploadBlob(appId, bytes, "image/png")      // BlobInfo(blobId base58, id hex, size)
val back = client.downloadBlob(appId, blob.blobId)
val content = client.blobContent(appId, blob.blobId)         // bytes + the content type served
val shared = client.downloadBlobGranted(appId, blobId, grant) // a run's grant: no session needed
val outbox = client.apps.xcalls(app = appId)                 // a component app's pending xcalls, dead letters
client.publishPresence(appId, seq = 1, state = "typing".encodeToByteArray())
client.presence(appId)
```
